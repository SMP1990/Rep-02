# Nayi chat shuru karne ka prompt

Jab bhi purani chat band ho jaye ya nayi chat shuru karni ho:

1. **claude.ai/code** kholen (Claude Code).
2. Repository **SMP1990/Rep-02** chunein. Agar branch chunne ka option ho to
   **`claude/upbeat-archimedes-266v06`** chunein.
3. Neeche wala poora prompt copy kar ke paste karein, aur aakhri line mein
   apna kaam likh dein.

---

```
Ye mera project "ASK Downloader" hai (live: social.al-marifat.org, Hostinger Web Apps, Node.js).
Sara code GitHub repo SMP1990/Rep-02 ki branch "claude/upbeat-archimedes-266v06" par hai.
Repo ki default branch (claude/hello-a3y98x) ek alag project hai — us par kaam mat karna.

Sab se pehle ye karo:
1. git fetch origin claude/upbeat-archimedes-266v06 aur usi branch ka code lo
   (agar tumhari apni nayi branch hai to usay isi branch par base karo, default branch par nahi).
2. In files ko poora parho: AI-HANDOVER.md, ask-downloader/CLAUDE.md, TOOLS-GUIDE.md.
3. Phir mujhe Roman Urdu mein 5-6 lines mein batao ke tum ne project ke bare mein kya samjha
   (kaun se tools bane hain, deploy kaise hota hai, mere rules kya hain). Abhi kuch change mat karna.

Mere rules (files mein bhi likhe hain): Roman Urdu mein jawab, step by step kaam aur har step ke baad
meri ijazat, pehle existing code check karna, site ki speed/security/SEO/purane features par koi asar
nahi, har cheez 11 zabanon mein, deploy sirf ZIP se (releases/ folder + GitHub download link),
aur pehle naap kar (measure) sahi tareeqa chunna — andaze par nahi.

Mera kaam: <yahan apna kaam likhein, maslan: "agla tool banana hai: Image Compressor">
```

---

**Note:** ye prompt sirf aisi AI ke saath poori tarah chalega jo GitHub repo
khud parh sakti ho, jaise Claude Code. Agar koi aur chatbot GitHub nahi parh
sakta, to usay `AI-HANDOVER.md` ka text copy kar ke de dein.
